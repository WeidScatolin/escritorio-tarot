# Escritorio do Tarot

Painel em pixel art, visto de cima, com os agentes da operacao de tarot no WhatsApp (tarologa, cobranca, gestora de anuncios), mais gasto em anuncios, faturamento e lucro liquido.

- Pagina estatica (`index.html`), sem build.
- Online: https://escritorio-tarot.vercel.app
- Estado atual: dados **ficticios**; ligacao com dados reais esta no backlog.
- O botao Chatwoot aponta para `http://localhost:3000` (so abre no PC onde o Chatwoot roda).
